A newspaper front page that sums up the world's news of Friday 13 November
2026 in one image: the Ukraine peace talks (Europe joins the next round),
Nvidia's chief resigns (shares fall 16%), the Microsoft 365 outage (Outlook
and Teams down in 74 countries), Hormuz tankers hit, the Gaza hospital
struck (six killed), and England beating Croatia.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` (JPEG, 1024x1024) to `$MAKEFUN_OUTPUT_DIR/entry.png`.
No network, no dependencies beyond the Python standard library.
